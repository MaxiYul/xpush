# XP USB Maker — загрузочная флешка Windows XP прямо с Android

Приложение с нуля (Java, без root, без сторонних библиотек). Работает через USB Host API (OTG),
Android 5.0+ (в том числе Android 8.1 x86). Создаёт флешку для установки Windows XP/2003 на ПК с BIOS/Legacy:

1. MBR (загрузчик Rufus), раздел FAT32 (LBA, активный, флаг 0x81 — «маскировка под второй диск»).
2. Загрузочная запись FAT32 → `NTLDR`.
3. Все файлы ISO (ISO9660/Joliet) на FAT32, длинные имена (LFN).
4. Правки как в Rufus (`SetupWinPE`): `SETUPLDR.BIN` → `NTLDR` (rdisk(0)→rdisk(1), `$WIN_NT$.~BT`→`i386`),
   копия `NTDETECT.COM` в корень, `TXTSETUP.SIF` с `SetupSourceDevice = "\device\harddisk1\partition1"`.

Загрузочные коды (MBR, загрузочная запись FAT32) взяты из Rufus/ms-sys (GPL) — поэтому проект под GPLv3.

## Как получить APK

Вариант А (проще, без установки чего-либо): GitHub.
1. Создайте репозиторий на github.com, загрузите туда содержимое этой папки.
2. Вкладка **Actions → Build APK → Run workflow**. Через несколько минут в артефактах будет `app-debug.apk`.

Вариант Б: Android Studio → Open → эта папка → Build → Build APK(s).
Либо в консоли (JDK 17 + Android SDK): `gradle assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`.

## Использование
1. Скопируйте ISO оригинального Windows XP SP3 (x86) во внутреннюю память.
2. Подключите флешку через OTG, откройте приложение: «Выбрать ISO» → «Найти флешку» → «Создать».
3. Загружайтесь с флешки в режиме Legacy/CSM (не UEFI), в BIOS — USB-HDD.

## Что проверено и что нет
Проверено на ПК автоматически (`host/run_host_tests.sh`): чтение ISO, разметка MBR, FAT32 (независимый
разбор: цепочки FAT, каталоги, LFN, FSInfo, резервные копии), содержимое файлов, правки SETUPLDR.BIN,
образы 200 МБ…40 ГБ, USB-протокол BOT/SCSI на программном эмуляторе со сбоями. Код компилируется против
android.jar API 27.

**НЕ проверено:** реальный запуск на USB-флешке и загрузка установщика XP на железе, сборка через Gradle.
Загрузочные записи взяты из Rufus без изменений, но успех установки зависит от BIOS/железа
(для SATA/AHCI на новых ПК XP требует драйверов — это ограничение самой XP).

## Ограничения
- Только BIOS/Legacy, только ISO XP/2003 с каталогом `I386`. Раздел ограничен 32 ГБ.
- Нужна флешка с секторами 512 байт, до 2 ТБ.
- Не сворачивайте приложение во время записи.
